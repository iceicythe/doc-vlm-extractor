# 人工复核与导出流程

演示界面现已支持“抽取—校验—人工修改—保存—重新载入—导出”。默认优先加载版式增强后的适配器；若本地不存在，则回退到原 `outputs/sft_v1/lora`。

## 使用

```powershell
$env:PYTHONUTF8 = "1"
.\venv-gld\Scripts\python.exe src\demo.py --check
.\venv-gld\Scripts\python.exe src\demo.py
```

1. 上传图片或选择测试样本，点击“开始抽取”。
2. 展开“人工复核与导出”，编辑模型原始 JSON。
3. 查看 Schema、数量×单价与行金额、明细金额之和与合计的提示。
4. 选择错误类型并填写备注，点击“保存复核并导出”。
5. 从“已保存复核记录”中重新载入，确认编辑结果保持一致。

校验遵循忠实提取原则。例如图上是“数量 10、单价 20、金额 180”，系统保留 180，只提示 `数量×单价=200`，不会自动改成 200。

## 审计记录

每次保存都会创建新的记录，不覆盖模型原始输出。JSON 记录包含：

- `sample_id`、图片路径、模型适配器指纹、提示词哈希、复核时间；
- 原始模型文本、原始解析结果、人工复核后的完整文档；
- 逐字段修改前后值、错误类型、备注；
- Schema 错误和金额关系提示。

同时导出 UTF-8 BOM 的 CSV，按表头、明细行、合计展开，便于 Excel 打开。记录默认保存在 `outputs/reviews-v1/`，该目录受 `.gitignore` 保护，避免把用户单据复核内容误提交到仓库。

固定错误类型为：文字识别错误、行列对应错误、漏字段/漏明细、无依据生成、结构或类型错误；同一单据可多选。
