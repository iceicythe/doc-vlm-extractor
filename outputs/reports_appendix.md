### 1.1 三条可复述的结论

1. **数据量与分辨率各自消灭一类错误，方向不同。**
   数据量消除「语义误读」（25% → 50% → 100% 时 17 → 7 → 5）；
   分辨率直接把它清零（5 → **0**），并把字符级误读再砍一半（74 → 29 → 16）。
2. **本地档的残余错误几乎全落在 `heavy` 退化档，且都是一字之差的字符级误读**
   （`36195`→`36193`、`Φ25`→`Φ12`），semantic 混淆为 0。
3. **幻觉 / 漏抽 / 行列错位 / JSON 非法在本地七个配置（基线 + 5 个消融组 + DPO）里全部为 0**
   —— 输出结构稳定，瓶颈纯粹在字符识别精度，不在结构理解。
   ⚠️ **这条不适用于两个 API 档**：`api_ds_abl` 出现 11 个漏抽，两档各有 59 / 29 个显著误读（见 §1.4 ⑧⑨）。

## 2 知识注入五配置

### 2.1 总表

| 档 | 预测源 | 模糊阈值 | 注入前 F1 | 注入后 F1 | Δ | fixed | broke | still_wrong | 仅统一写法 |

| ⑤ API 开思考（旧口径） | `eval_api_ds_abl` | 0.50 | 0.9546 | 0.9709 | +0.0163 | 55 | 0 | 3 | 144 |
| ⑤ API 关思考（正式口径） | `eval_api_ds_abl_nothk` | 0.50 | 0.9681 | **0.9790** | +0.0109 | 37 | 0 | 3 | 162 |

统一设置：词表 `data/lexicon/v1.json`（2100 条训练样本的 GT 值域）；
纠正字段 `明细.名称 / 明细.规格型号 / 明细.单位 / 表头.项目名称`；跳过 `表头.供应商 / 表头.单据编号`。

> **精确命中不改变分数**（打分前本来就会归一化），它只统一输出写法。
> 真正影响指标的是模糊替换，上表 fixed / broke 都出自它。

### 2.2 三条结论

1. **收益与基座能力成反比**：+0.0522（零样本）/ +0.0109（API）/ −0.0003（SFT）。
   SFT 之后**词表已被权重内化**，后处理无事可做 —— 203 处改动里只有 1 处模糊替换，还是个 broke。
2. **阈值放宽更划算**：0.50 相对 0.70，fixed 169 vs 122，而 **broke 两边都是 0**。
   broke 为 0 说明放宽没有"改坏"风险，抬高阈值只是少改；阈值降到 0.40 以下才真正变差
   （新增改动的有效率 92% → 43%，完整扫描见 `report_inject_sweep.md`）。
3. **能力边界由词表覆盖率决定**：按「GT 值是否在词表内」分桶 ——
   零样本档 1258 个可救实例里修好 169 个；词表外那 2 个实例 **0 fixed / 1 broke**，就是纠正的禁区。
   零样本档未被纠正的 128 个错误，全部是"模型错、且词表里找不到足够近的值"。

## 3 ② 零样本档的错误全貌

零样本档是**唯一 7 类错误全部出现**的配置（871 错 / 26.93%，字段总数 3234，JSON 合法 98/102）：

| 类型 | 数量 | 占错误 | 占全部字段 |
|---|---:|---:|---:|
| 文本近似误读 | 301 | 34.6% | 9.31% |
| 数值误读 | 235 | 27.0% | 7.27% |
| 文本显著误读 | 173 | 19.9% | 5.35% |
| 漏抽 | 144 | 16.5% | 4.45% |
| 多抽 / 幻觉 | 11 | 1.3% | 0.34% |
| JSON 非法 | 4 | 0.5% | 0.12% |
| 行列错位 | 3 | 0.3% | 0.09% |

按档：clean 258 / medium 204 / heavy 409。
按结构：表头 286 / 明细 448 / **合计 98** / 明细(未配对) 24 / schema 外 11。

**最值得记的一条**：`合计.金额` 98 个实例**全部漏抽（98/98 = 100%）**，
连带项名称 80.61%、单据编号 79.59%、供应商 87.76% 全线崩。
⇒ **零样本不是"读不准合计行"，而是根本没把合计行当成要抽的对象**；SFT 之后该项立刻归零。
这与「prompt 只决定天花板高度、模型能力决定能接近多少」是同一件事的两个侧面。

其余要点：漏抽 144 ≫ 幻觉 11（**零样本偏保守**，倾向不输出）；
幻觉 11 个全是「层级放错」（把该进 `表头` 的字段放到了顶层，如 `顶层.项目名称`）。
