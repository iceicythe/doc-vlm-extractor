三条结论

  • 分辨率是主导因素。384→512 涨 1.3 个点，384→768 涨 1.7 个点， 增益全部来自 heavy 档（0.9635→0.9870）；clean 档早已到顶（1.0000）。
  • 数据量曲线 25%→50%→100% 为 0.9666→0.9731→0.9782，单调且增量递减 （+0.65pt / +0.51pt）→ 350 个源样本接近饱和，继续堆数据的边际收益 低于换更大输入分辨率。
  • 冻结视觉层几乎无代价。仅训语言层 0.9790 vs 全层 0.9782，差 0.0008 ≈ 3 个字段，属噪声 → 显存紧张时可放心不训视觉塔。

两条面试级细节

  • 两类错误各有各的解法。数据量消除语义误读（17→7→5）； 分辨率把它清零并顺带砍掉一半字符误读（74→29→16）。 只调其中一个都会留下另一类错误。
  • 结构层零错误。幻觉 / 漏抽 / 行列错位 / JSON 非法在全部六个配置里都是 0 —— 瓶颈纯粹在字符识别精度，不在版面理解。
